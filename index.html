HOPIT

กระโดด หลบหลีก เรียนรู้ผ่านการเล่น

HOPIT คือเกมโต้ตอบที่พัฒนาด้วย Arduino Uno R4 WiFi และเซนเซอร์อัลตราโซนิก ผู้เล่นจะควบคุมกบให้กระโดดหลบก้อนหินที่เข้ามาขวางทาง โดยเซนเซอร์จะตรวจจับระยะหรือการเคลื่อนไหวของผู้เล่น เพื่อให้การเล่นจริงส่งผลต่อเกมบนจอแสดงผล

บทคัดย่อ

HOPIT เป็นโครงงานเกมโต้ตอบที่พัฒนาขึ้นโดยใช้ไมโครคอนโทรลเลอร์ Arduino Uno R4 WiFi ร่วมกับเซนเซอร์อัลตราโซนิก โดยมีวัตถุประสงค์เพื่อผสานความรู้พื้นฐานด้านการเขียนโปรแกรม อุปกรณ์อิเล็กทรอนิกส์ และการออกแบบเกมเข้าด้วยกัน ให้กลายเป็นประสบการณ์การเล่นเกมที่ผู้เล่นได้โต้ตอบกับอุปกรณ์จริง

เกมมีตัวละครเป็นกบที่ต้องกระโดดข้ามก้อนหินซึ่งปรากฏขึ้นเป็นสิ่งกีดขวาง เซนเซอร์อัลตราโซนิกทำหน้าที่ตรวจจับระยะหรือการโต้ตอบของผู้เล่น จากนั้น Arduino จะประมวลผลข้อมูลจากเซนเซอร์เพื่อกำหนดพฤติกรรมของเกม และมีจอ LCD สำหรับแสดงข้อมูลที่เกี่ยวข้อง เช่น สถานะของเกมหรือคะแนน ตามโปรแกรมที่พัฒนาขึ้น

ระบบประกอบด้วยบอร์ด Arduino Uno R4 WiFi, Breadboard, สายจัมเปอร์, จอ LCD, เซนเซอร์อัลตราโซนิก และกล่องที่ออกแบบและประดิษฐ์ขึ้นเอง โครงงานนี้แสดงให้เห็นแนวทางการนำไมโครคอนโทรลเลอร์และเซนเซอร์วัดระยะมาบูรณาการเป็นเกมโต้ตอบ และเปิดโอกาสให้ได้เรียนรู้เรื่องการเขียนโปรแกรมระบบฝังตัว การเชื่อมต่อฮาร์ดแวร์ และปฏิสัมพันธ์ระหว่างมนุษย์กับอุปกรณ์

อุปกรณ์อิเล็กทรอนิกส์

ใช้บอร์ด Arduino Uno R4 WiFi ร่วมกับเซนเซอร์อัลตราโซนิกเป็นหัวใจของระบบ

การโต้ตอบ

ตรวจจับระยะและการโต้ตอบทางกายภาพของผู้เล่น เพื่อใช้ควบคุมเกม

การออกแบบเกม

กบที่ต้องกระโดดข้ามก้อนหินซึ่งเป็นสิ่งกีดขวาง ในสไตล์พิกเซลอาร์ต

รายละเอียดโครงงาน

รวบรวมภาพรวม อุปกรณ์ ตัวอย่างโค้ด ซอร์สโค้ด วิดีโอ ภาพประกอบ และสมาชิกในทีม

อุปกรณ์ที่ใช้

อุปกรณ์ทั้งหกชิ้นที่ประกอบกันเป็นเกม HOPIT

Arduino Uno R4 WiFi

บอร์ดไมโครคอนโทรลเลอร์ที่ทำหน้าที่ประมวลผลข้อมูลจากเซนเซอร์และควบคุมการทำงานของเกม

Breadboard

แผงต่อวงจรสำหรับเชื่อมต่ออุปกรณ์อิเล็กทรอนิกส์โดยไม่ต้องบัดกรี

Jumper wires

สายไฟสำหรับเชื่อมต่อขาของบอร์ด เซนเซอร์ และจอแสดงผลเข้าด้วยกัน

LCD Screen

จอแสดงผลสำหรับแสดงข้อมูลของเกม เช่น สถานะเกมหรือคะแนน ตามที่โปรแกรมกำหนด

Ultrasonic Sensor

เซนเซอร์สำหรับวัดระยะ เพื่อตรวจจับการเคลื่อนไหวหรือการโต้ตอบของผู้เล่น

กล่องที่ทำขึ้นเอง Custom-made box

กล่องที่ออกแบบและประดิษฐ์เองสำหรับบรรจุอุปกรณ์ พร้อมลวดลายกบและบ่อน้ำสไตล์พิกเซล
